# Project Tickets

Internal tracking for paper-prep work. Four files:

- `ACTIVE.md` — in-progress work right now
- `BACKLOG.md` — planned future work, not yet started
- `DONE.md` — completed work, kept for reference
- `KNOWLEDGE.md` — non-obvious facts we've learned; check here before changing defaults

## Conventions

- Each ticket: `## [TAG] Short Title` header, then a few bullets
- Tags: `[TEACHER]`, `[CD]`, `[PD]`, `[RF]`, `[MFM]`, `[MOMENT]`, `[EVAL]`, `[PAPER]`, `[INFRA]`
- When moving ACTIVE → DONE, keep the full ticket text and append `**Outcome:**` + a sentence
- Update `KNOWLEDGE.md` whenever a non-obvious finding could affect future decisions
